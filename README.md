## 🌟 أبرز التحديثات والميزات الجذرية في الإصدار 3.0:

1. **قاعدة بيانات SQLite3 دائمة (`bot_database.db`)**:
   - تم التخلص تماماً من مشكلة فقدان البيانات ومسح الإعدادات عند إعادة النشر على الاستضافات السحابية.
   - مزامنة تلقائية ثنائية الاتجاه مع `sources.json` و `state.json` لضمان التوافق التام مع تطبيق Bots.Business.

2. **محرك سحب مزدوج موثوق (MTProto + Scraper)**:
   - دعم مباشر لـ **Telethon MTProto** لقراءة القنوات العامة والخاصة عبر حساب المشرف.
   - إصلاح الخلل القاتل في الـ Regex وتصحيح استخراج النصوص والوسائط.
   - فحص ونشر **كافة المنشورات الجديدة** المتراكمة بالترتيب الزمني وليس المنشور الأخير فقط.

3. **طابور معالجة غير متزامن (Worker Thread + Queue)**:
   - معالجة المنشورات والذكاء الاصطناعي في خيط مستقل تماماً، مما يمنع تجمد البوت أو انقطاع `getUpdates`.

4. **نظام حسابات وتفويض بالهاتف الرسمي (Telegram Contact Verification)**:
   - زر مدمج بمشاركة الرقم الرسمي `request_contact=True` وتوثيقه في جدول `users`.
   - أوامر: `/register`، `/my_account`، وإدارة الصلاحيات (Admin / Moderator / User) ونظام الاشتراكات.

5. **فاحص الصلاحيات الدوري وقوة الاتصال**:
   - فحص آلي كل 30 دقيقة لصلاحيات البوت في كافة القنوات المعتمدة وتنبيه المشرف فوراً إن انقطعت الصلاحية.
   - معالجة أخطاء `getUpdates` (مثل 409 Conflict و 429 Too Many Requests) مع Exponential Backoff.
   - شهادات SSL نظامية معتمدة.

6. **إصلاح زر إعادة الصياغة التفاعلي (`panel_test`)**:
   - دعم كامل لإعادة صياغة المنشورات الموجهة (Forward) بضغطة زر ونشرها فوراً.

## 🚀 خيارات النشر والتشغيل:

### 1. التشغيل عبر Docker و Docker Compose (لـ VPS / Railway / Render):
```bash
# بناء وتشغيل الحاوية
docker compose up -d --build

# عرض السجلات المباشرة
docker compose logs -f
```

### 2. التشغيل المباشر عبر Python:
```bash
pip install -r requirements.txt
python3 main.py
```

### 3. التشغيل في Bots.Business:
- تم ربط كافة أوامر مجلد `commands/` بملف `bot.json`.
- يمكن المزامنة مباشرة مع المستودع على فرع `fix/major`.

## 🎛 أهم أوامر تيليجرام:
- `/start` : فتح لوحة التحكم الرئيسية بالأزرار التفاعلية.
- `/register` : مشاركة رقم هاتفك للتوثيق الرسمي وفتح الصلاحيات.
- `/my_account` : عرض بيانات الحساب، الرصيد، ونوع الخطة وتاريخ الانتهاء.
- `/crawl_sources` : فحص وسحب أحدث المنشورات من كافة القنوات المراقبة فوراً.
- `/new_post` : إرسال وصياغة خبر فوري ونشره في قنواتك المعتمدة.
- `/test` : تجربة الصياغة الأكاديمية بنموذج DeepSeek-V4-Flash.
- `/users` : (للمشرف) عرض قائمة المستخدمين المسجلين وأرقامهم.
- `/ban <id>` و `/unban <id>` : (للمشرف) حظر أو رفع الحظر عن مستخدم.
